VOXPrint AI Lucent
Copyright 2026 Aleksandr Mitroshenkov
Publisher: VOXPrint AI Suite

Per-machine install under C:\Program Files\VOXPrint AI Suite\Lucent.
The Start menu folder is VOXPrint AI Suite. The shortcut is VOXPrint AI Lucent.
Lucent appears in "Open with" for AVIF, JPEG XL, WebP, JPEG, PNG, GIF, BMP and TIFF.

voxprint-lucent.exe is the viewer. voxprint-lucent-cli.exe is the console entry.
Neither needs an NVIDIA GPU.
python\python.exe (Python 3.14) runs the tools and the Enlarge client (PySide6).
Press I in the viewer, or run voxprint-lucent-tools.cmd --path IMAGE.
Enlarge is a separate suite app. When it is not installed, the Enlarge action
is disabled and everything else works.

Setup records Lucent in %LOCALAPPDATA%\VOXPrint AI Suite\state\installed-apps.json.
An older per-user install (display name "Voxprint AI Lucent") is removed during setup.
Files under %LOCALAPPDATA%\Voxprint that you created stay.

Uninstall from Windows Settings, Apps, VOXPrint AI Lucent.
