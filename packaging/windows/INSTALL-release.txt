VOXPrint AI Lucent 0.1.0-rc7
Copyright 2026 Aleksandr Mitroshenkov
Publisher: VOXPrint AI Suite

Per-machine install under C:\Program Files\VOXPrint AI Suite\Lucent.
The Start menu folder is VOXPrint AI Suite. The shortcut is VOXPrint AI Lucent.

voxprint-lucent.exe is the viewer. voxprint-lucent-cli.exe is the console entry.
Neither needs an NVIDIA GPU.
python\python.exe is the tools and Enlarge client (PySide6). Press I in the
viewer, or run voxprint-lucent-tools.cmd --path IMAGE.
Enlarge itself is a separate app. This install only contains the client.

An older per-user install (display name "Voxprint AI Lucent", under
%LOCALAPPDATA%\Voxprint\Lucent) is not removed by this package. Run
remove-legacy-user.ps1 before installing, or uninstall that app in Settings.
Files under %LOCALAPPDATA%\Voxprint that you created stay either way.

Uninstall from Windows Settings, Apps, VOXPrint AI Lucent.

The measurement zip (Run-M0.ps1 and Run-Checks.ps1) is a separate download from the same release.
