# M3 Enlarge hand-off

Lucent's Enlarge client lives in the tools process. The C++ viewer does not talk to Enlarge, and `--benchmark` does not start the tools process. The 250 ms first-pixel guard is unchanged.

The product Enlarge server is not available yet. CI runs the client against `python -m voxprint_lucent.enlarge_mock`, which speaks protocol 1. The contract is [IPC-ENLARGE.md](IPC-ENLARGE.md). The shared spec in project-notes was not readable from this checkout (GitHub returned 404).

## What works

- Discovery reads `LUCENT_ENLARGE_EXE`, then `voxprint-enlarge` on `PATH`, then the Linux desktop file or the Windows `HKCU\Software\Voxprint\Enlarge` key.
- `--capabilities --json` decides whether the actions are shown. `gpu.status` `none` hides them and shows the reason. `warn` leaves them visible and puts the reason on the tooltip, which is how a below-RTX-40 GPU is reported.
- Quick enlarge and Open in Enlarge send `hello` and `enlarge.request` on the local socket. The client starts `voxprint-enlarge --serve --hidden` when nothing is listening, waits up to 3 seconds, and falls back to `--json-progress` if the socket never comes up.
- Progress, `done`, and `error` (including `model_missing`) are handled. Cancel sends the `cancel` message. A CLI run is stopped by terminating the process.
- The default result is `<name>.enlarged-<scale>x.avif` beside the source. PNG is rejected. The source is never overwritten.
- The compare view is a split slider with one zoom and one pan for both sides. Keep leaves the result. Reveal opens the folder. Discard deletes the result and leaves the source. The view is painted with `ROOT_PLAIN` `#17171c` and the accent `#60a5fa`.

`--enlarge --path IMAGE` opens that window. `I` opens the info panel in the same process.

## Checks

`tests/test_enlarge.py` covers the capabilities object (including `gpu.status` `none` and a reason), the CLI progress stream, `model_missing`, the socket hello / request / done path, cancel, the CLI fallback, the split colours, zoom around the cursor, and Keep / Discard.
