# Voxprint AI Lucent: decisions

Image viewer of the Voxprint AI Media Suite. Created 2026-10-10. This copy lives in the code repository. Paths such as `../suite/` refer to the suite notes tree. Based on the viewer research (`voxprint-viewer/RESEARCH.md` on the box, summarised below) and the suite rules in [suite/COLLABORATION.md](../suite/COLLABORATION.md) section 3. Owner decisions are marked with their source; technical decisions are made by Lucent per [PREFERENCES.md](../PREFERENCES.md) ("the assistant makes all technical decisions autonomously").

## Decided

1. **Name:** "Voxprint AI Lucent" (Aleksandr, 2026-10-10). Short name `lucent`; executable `voxprint-lucent`; Linux app id `ai.voxprint.Lucent`. Never "Glass", "Kobe" or an ImageGlass-lookalike logo/palette.
2. **What it is:** a fast, native, local image viewer for Windows 11 24H2+ and Linux 2025+, with modern formats (AVIF, JPEG XL, WebP, HEIF via system codec, RAW, EXR) as first-class citizens, colour management, and a one-click hand-off to Voxprint AI Enlarge. An open alternative to Windows Photos and to open-core viewers.
3. **Licence:** Apache-2.0 + `NOTICE` ("Copyright 2026 Aleksandr Mitroshenkov") (suite rule). Dependencies linked dynamically where LGPL (Qt/PySide6, LibRaw, KImageFormats). No GPL code (exiv2 avoided).
4. **Clean-room:** no ImageGlass code, assets, themes, icons, config/theme formats or SDK protocol (ImageGlass is GPL-3.0 open-core with trademarked name/logo). Feature ideas only. Oculante (MIT) may be read; GPL viewers (qView, nomacs, qimgv, Loupe, JPEGView) are ideas-only. No compatibility with ImageGlass plugin/theme formats.
5. **GPU: exception to the suite RTX 40 rule** (Aleksandr via Voxprint AI Suite Lead, 2026-10-10). Lucent does **not** require an RTX GPU; it renders through Qt RHI (D3D12 on Windows, Vulkan on Linux) on any modern GPU, iGPU included. Only the "Enlarge" action depends on Enlarge and its GPU support (Enlarge warns below RTX 40, see [enlarge/DECISIONS.md](../enlarge/DECISIONS.md)).
6. **Network and diagnostics policy** (Aleksandr via Voxprint AI Suite Lead, 2026-10-10, refined the same day; replaces the research's "zero network"; matches the suite rule in COLLABORATION section 3):
   - **Allowed:** an update check against our own GitHub releases so the app can update itself; any network request the user explicitly triggers (e.g. "Check for updates now", opening a link).
   - **Statistics / diagnostics: strictly opt-in.** Off by default. Only the user turns collection on (Settings switch, clearly explained), or sends a report himself (e.g. "Send diagnostic report" after a crash, showing what will be sent). No resident or background collection without his knowledge.
   - **Forbidden:** telemetry, usage statistics, analytics or crash upload that are on by default or run silently.
   - The update check is a plain HTTPS GET of the public releases feed: no identifiers, no usage tokens in the User-Agent or query string, no cookies (it is not a statistics channel).
   - No other background traffic. Image viewing and the Enlarge hand-off are fully local.
7. **Executable (Suite Lead approved Plan B, 2026-10-10).** `voxprint-lucent` is C++/Qt 6, Qt 6.12, the same Qt line as PySide6 6.12. It owns startup, the single instance, decode, the look-ahead cache, and rendering. M0 paints the first image with `QPainter` so the startup measurement does not include RHI init. M1 uses Qt RHI for zoom and pan (D3D12 on Windows, Vulkan on Linux) after that first pixel. Decode is Qt image plugins plus KImageFormats built against the bundled Qt (AVIF, JPEG XL). `QImageReader::setScaledSize` is JPEG-only. HEIF stays the system codec: the KImageFormats HEIF plugin is not built, and libde265 and x265 are not shipped. Rust/egui stays rejected.
8. **On-demand tools process.** Settings, tools, the info panel, the Enlarge UI, and the updater run as `voxprint-lucent-tools` (Python 3.14 + PySide6-Essentials 6.12) and are not launched to open an image. PySide6 missed the 250 ms cold first-pixel budget, including a Nuitka onedir build. That optimisation stopped when Plan B was approved. Numbers are in [M0-RESULTS.md](M0-RESULTS.md).
9. **Single instance** via `QLocalServer`: a second launch forwards its paths to the running window. Optional tray residency is opt-in only (no resident "startup boost" by default).
10. **Design:** shared blue + yellow theme from [suite/design/PALETTE.md](../suite/design/PALETTE.md) on Acrylic (Win11), plain dark on Linux; yellow primary actions, soft blue menus/lists/accents; WCAG AA contrast test like the other apps. Splash identity colour: `#60a5fa` (ACCENT), approved for this repository (owner requirement, 2026-10-10). The palette is voxprint-common's `tokens.json`, vendored as `share/tokens.json` and substituted into `share/lucent.qss.in` for both the C++ executable and the PySide6 tools host. Public screenshots on the pinned Alpengluehen backdrop. M0 does not show a blocking splash before the first pixel; the colour is the theme accent and the frameless window border.
11. **Output formats (suite rule):** Lucent mainly reads. Where it writes (crop/rotate save-as, frame export, "save a copy"), the default is **AVIF**, with JPEG XL (incl. lossless) and WebP. **No PNG output.** JPEG and HEIC (system codec only) are legacy options, never default. Lossless in-place operations keep the source format (JPEG rotate via libjpeg-turbo transforms, JXL lossless).
12. **Platforms and CPU (suite rule):** Windows 11 24H2+ x64 and Linux 2025+ (Wayland first). Build for x86-64-v3 (AVX2, FMA) + AVX-VNNI, no AVX-512 assumption, no 32-bit, no legacy fallbacks. Keep code ARM-friendly; no ARM builds now.
13. **Formats:** HEIF/HEIC only through the system codec (Windows WIC extensions, Linux system libheif); never bundle libde265/x265. Missing codec -> "install the codec" hint. Respect EXIF orientation everywhere; colour-manage embedded ICC -> monitor profile (lcms2).
14. **Enlarge hand-off:** discovery via a registry/`.desktop` entry plus `voxprint-enlarge --capabilities --json`. **Lucent calls the headless CLI** (`--json-progress`) and does not open the socket. Enlarge may still keep that socket behind its own CLI. **No URI scheme, no COM/D-Bus.** Files are passed by path, never pixels; results never overwrite the source. Agreed 2026-10-10 in [IPC-ENLARGE.md](IPC-ENLARGE.md) and [APP-DISCOVERY.md](APP-DISCOVERY.md). The caller rule is the suite CLI hand-off from the same day. The server side remains Enlarge's.
15. **Repo:** `Mitroshenkov87/voxprint-lucent`. The owner is making it public. The update check reads that repository's GitHub releases.
16. **M1 rendering split (2026-10-10).** `--benchmark` stays on `Viewer` and does not construct the folder list, the look-ahead cache, or `QRhiWidget`. The interactive window may create `QRhiWidget` only after the first raster paint (D3D12 on Windows, Vulkan on Linux). `LUCENT_RHI=0` keeps `QPainter`. JPEG `setScaledSize` is unchanged. JPEG XL also requests `ScaledSize` when the plugin advertises that option; zoom past 1:1 decodes full resolution. Look-ahead uses two worker threads. AVIF and JPEG XL threading inside KImageFormats is left to those plugins. HEIF, RAW, and EXR are system plugins only. Embedded ICC is converted to sRGB with Qt's color space; a separate lcms2 monitor-profile link is not part of M1.
17. **Startup budgets (owner, 2026-10-11).** A first visible pixel is at most 250 ms, whether that pixel is an embedded preview or the full image. A warm full-resolution decode of a 12 megapixel or larger AVIF or JPEG XL is at most 350 ms. JPEG and WebP warm stay at 250 ms. The cold JPEG first-launch gate stays 250 ms. Cached next/previous stays 30 ms. CI enforces the 250 ms figure on a tiny JPEG. `bench/Run-M0.ps1` writes `warm_gate` for the 350 ms figure. One measurement of thumbnail and dav1d shortcuts is in [CI.md](CI.md). The decode path is unchanged.
18. **Install layout (owner, 2026-10-11).** The display name is `VOXPrint AI Lucent`. The Windows installer is per-machine under `C:\Program Files\VOXPrint AI Suite\Lucent`, publisher `VOXPrint AI Suite`, Start menu folder `VOXPrint AI Suite`. Linux installs under `/opt/voxprint-ai-suite/lucent/`. Registration is `HKLM\Software\VOXPrint\Lucent`. A nested uninstall of the rc6 per-user MSI is not possible from inside this package; `remove-legacy-user.ps1` does that before install. Per-user data stays in `%LOCALAPPDATA%\Voxprint`.

## Open questions

- **Updates while the repo is private:** the self-update check needs a public releases feed. Until the first public release there is nothing to check; decide later whether updates use the GitHub releases API directly or a small static manifest asset attached to each release. Default proposal: on by default, at most once per day, with a Settings switch and a manual "Check now" button; reuse Audiobook Builder's exe-patch updater.
- **Reference-laptop confirmation:** run `bench/Run-M0.ps1` on Windows 11 or Windows Server 2025 with Defender real-time protection on, right after reboot. That confirms the C++ numbers. It does not block M1. A median of ten independent cold starts would need ten reboots; the script records the first post-reboot launch separately from the in-session median and nearest-rank p95. CI virtual machines stay indicative.
- **Shared discovery module:** Lucent carries `voxprint_lucent/discovery.py`, a copy of [APP-DISCOVERY.md](APP-DISCOVERY.md), until `voxprint-common` is approved.
- **Enlarge protocol:** agreed 2026-10-10. See [IPC-ENLARGE.md](IPC-ENLARGE.md). The product server is not in this repository yet.
