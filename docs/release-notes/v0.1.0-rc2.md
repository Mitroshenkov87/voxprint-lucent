# Voxprint AI Lucent v0.1.0-rc2

Pre-release. `v0.1.0-rc1` remains the keyboard-only tag. This one adds the viewer chrome.

Windows: `VoxprintAILucent-0.1.0-rc2-win64.msi`. It is a per-user install (no administrator) under `%LOCALAPPDATA%\Voxprint\Lucent`. The package contains the C++ viewer, the Qt 6.12 runtime, the AVIF and JPEG XL plugins, and the PySide6 tools and Enlarge client.

The measurement bundle is `lucent-0.1.0-rc2-windows.zip`. Unzip it and run `Run-M0.ps1` with Defender real-time protection left on. A cold sample is the first launch after a reboot.

Linux: `voxprint-lucent_0.1.0~rc2_amd64.deb`. The viewer and Qt 6.12 are bundled. AVIF and JPEG XL plugins are not in this package; the Windows installer has them. A system `libavif` is used for the splash and welcome pictures when Qt has no AVIF plugin.

Check `SHA256SUMS` against the download.

## This build

- Slim auto-hiding toolbar, right-click menu, thumbnail strip, and an app menu with settings, hotkeys, language, and about.
- Splash on launch, dismissed when the picture is presented. Welcome picture on the first three launches that have no file.
- The viewer builds on Debian 13's Qt 6.8. CMake links GuiPrivate only when that target's include directories exist, and the Debian job installs qt6-base-private-dev so `rhi/qrhi.h` is present.
- `--benchmark` is still the first-pixel path. The 250 ms guard is unchanged.

## Not in this build

Enlarge's server is not in this repository. The client and mock are. Colour management stops at sRGB. A monitor profile is not applied.
