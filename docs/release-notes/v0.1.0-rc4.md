# Voxprint AI Lucent v0.1.0-rc4

The GitHub release title is `0.1.0 RC · build N "Ner"`. `N` is this release workflow's run number plus the offset in `BUILD.json`. The offset stays 0. The same string is in About, on the splash, and in `voxprint-lucent --version`.

Windows: `VoxprintAILucent-0.1.0-rc4-win64.msi`. It is a per-user install (no administrator) under `%LOCALAPPDATA%\Voxprint\Lucent`. The package contains the C++ viewer, the Qt 6.12 runtime, the AVIF and JPEG XL plugins, and the PySide6 tools and Enlarge client.

The measurement bundle is `lucent-0.1.0-rc4-windows.zip`. Unzip it and run `Run-M0.ps1` with Defender real-time protection left on. A cold sample is the first launch after a reboot. `Run-Checks.ps1` is the short headless pass: `--version`, Enlarge `--capabilities --json`, the Enlarge `--dry-run` hand-off, and `--benchmark` on each file in `images\hard`. It writes `results\checks.json`.

Those files are generated while the zip is built. They are not photographs. The set is AVIF 4:2:0 and 4:4:4 at 12 megapixels, AVIF 10-bit PQ, JPEG XL lossy, lossless, and progressive, JPEG XL PQ, an animated WebP, a 24 megapixel JPEG with EXIF orientation 6, and a wide-gamut JPEG with an ICC profile.

Linux: `voxprint-lucent_0.1.0~rc4_amd64.deb`. The package contains the viewer and the Qt runtime it was built with. AVIF and JPEG XL plugins are not in the Linux package.

`SHA256SUMS` lists every file.

## In this build

- The public docs site is published from `main`.
- Enlarge is handed off with the v0.2.0-rc.1 command: published flags, exit codes, and file names. The process does not open a window.
- The measurement zip adds `images\hard` and `Run-Checks.ps1`.

`v0.1.0-rc3` remains the previous published pre-release.
