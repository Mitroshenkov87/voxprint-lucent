# Voxprint AI Lucent v0.1.0-rc5

The GitHub release title is `0.1.0 RC · build N "Yashar"`. `N` is this release workflow's run number plus the offset in `BUILD.json`. The offset stays 0. The same string is in About, on the splash, and in `voxprint-lucent --version`.

## Highlights

- The Enlarge hand-off uses a still image and an absolute path. A multi-frame file sends the frame on screen.
- An installed Enlarge is found from its registry entry, App Paths, or the shared suite manifest.
- The Windows installer records InstallPath, Exe, Version, IpcName, and ProtocolVersion, plus App Paths.
- AVIF and JPEG XL decode on every core so the first pixel arrives sooner.
- The cold-start measurement task keeps a working directory and a log, and it stays registered until a result file exists.
- PQ and HLG pictures are tone-mapped for an SDR screen. When the display offers HDR, those pixels stay in a high-dynamic-range buffer.
- The installer copies the runtime Lucent needs. `voxprint-lucent --selftest --json` reports whether the readers are present.

## Install

**Windows.** Run `VoxprintAILucent-0.1.0-rc5-win64.msi`. It is a per-user install (no administrator) under `%LOCALAPPDATA%\Voxprint\Lucent`. The package contains the C++ viewer, the Qt 6.12 runtime, the Visual C++ runtime, the AVIF and JPEG XL plugins, and the PySide6 tools and Enlarge client.

The measurement bundle is `lucent-0.1.0-rc5-windows.zip`. Unzip it and run `Run-M0.ps1` with Defender real-time protection left on. A cold sample is the first launch after a reboot. `Run-Checks.ps1` is the short headless pass: `--version`, Enlarge `--capabilities --json`, the Enlarge `--dry-run` hand-off, and `--benchmark` on each file in `images\hard`. It writes `results\checks.json`.

Those files are generated while the zip is built. They are not photographs. The set is AVIF 4:2:0 and 4:4:4 at 12 megapixels, AVIF 10-bit PQ, JPEG XL lossy, lossless, and progressive, JPEG XL PQ, an animated WebP, a 24 megapixel JPEG with EXIF orientation 6, and a wide-gamut JPEG with an ICC profile.

**Linux.** Install `voxprint-lucent_0.1.0~rc5_amd64.deb` (the download name uses a dot: `voxprint-lucent_0.1.0.rc5_amd64.deb`).

```bash
sudo apt install ./voxprint-lucent_0.1.0.rc5_amd64.deb
```

The package contains the viewer, the Qt runtime it was built with, and the JPEG and WebP plugins. AVIF and JPEG XL plugins are in the Windows installer. On Linux, `voxprint-lucent --selftest --json` reports those two readers as missing and still reports overall success when JPEG is present.

`SHA256SUMS` lists every file. The hashes are repeated under Checksums on this release.

`v0.1.0-rc4` remains the previous published pre-release.
