# Voxprint AI Lucent v0.1.0-rc6

The GitHub release title is `0.1.0 RC · build 7 "Tov"`. That number is the `number` field in `BUILD.json`. About, the splash, and `voxprint-lucent --version` use the same string.

## Highlights

- PQ and HLG pictures on an SDR screen roll off with the BT.2390 curve. Highlights bend into the peak instead of cutting to a flat wash. An HDR display still keeps a high-dynamic-range buffer.
- The cold-start task removes itself after it has written a result, and `m0-task.log` records `outcome=wrote` and `outcome=unregistered`. If Windows will not remove a task that is still running, a follow-up process removes it and writes the same line.
- When the PySide6 comparison cannot produce a sample, the measurement JSON says `status` `skipped` and a one-line `reason`. The harness copies `BUILD.json` next to that package so `--version` can read it.
- `Run-Checks.ps1` writes `results\checks.json` as UTF-8 without a BOM, and it reads the viewer's version as UTF-8.
- A repeated Enlarge model id is shown once.
- `scripts/vm_test.sh` (and `scripts/vm_test.ps1` on Windows) is the non-interactive smoke. Exit 0 is pass, 1 is a failed check, 2 is setup, and 3 is no GPU only when `--require-gpu` is set. Viewing does not need a GPU.

Warm first pixel on the 8 vCPU measurement is still over 250 ms for AVIF (296 ms) and JPEG XL (253 ms, p95 338 ms). JPEG and WebP are inside the budget. A lower-resolution colour conversion does not remove the AV1 or JPEG XL decode, which is where that time goes.

## Install

**Windows.** Run `VoxprintAILucent-0.1.0-rc6-win64.msi`. It is a per-user install (no administrator) under `%LOCALAPPDATA%\Voxprint\Lucent`. The package contains the C++ viewer, the Qt 6.12 runtime, the Visual C++ runtime, the AVIF and JPEG XL plugins, and the PySide6 tools and Enlarge client.

The measurement bundle is `lucent-0.1.0-rc6-windows.zip`. Unzip it and run `Run-M0.ps1` with Defender real-time protection left on. A cold sample is the first launch after a reboot. `Run-Checks.ps1` is the short headless pass: `--version`, Enlarge `--capabilities --json`, the Enlarge `--dry-run` hand-off, and `--benchmark` on each file in `images\hard`. It writes `results\checks.json`. `vm_test.ps1 --smoke --json` is the same kind of pass for the suite runner.

Those files are generated while the zip is built. They are not photographs. The set is AVIF 4:2:0 and 4:4:4 at 12 megapixels, AVIF 10-bit PQ, JPEG XL lossy, lossless, and progressive, JPEG XL PQ, an animated WebP, a 24 megapixel JPEG with EXIF orientation 6, and a wide-gamut JPEG with an ICC profile.

**Linux.** Install `voxprint-lucent_0.1.0~rc6_amd64.deb` (the download name uses a dot: `voxprint-lucent_0.1.0.rc6_amd64.deb`).

```bash
sudo apt install ./voxprint-lucent_0.1.0.rc6_amd64.deb
```

The package contains the viewer, the Qt runtime it was built with, and the JPEG and WebP plugins. AVIF and JPEG XL plugins are in the Windows installer. On Linux, `voxprint-lucent --selftest --json` reports those two readers as missing and still reports overall success when JPEG is present.

`SHA256SUMS` lists every file. The hashes are repeated under Checksums on this release.

`v0.1.0-rc5` remains the previous published pre-release.
