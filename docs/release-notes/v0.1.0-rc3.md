# Voxprint AI Lucent v0.1.0-rc3

The GitHub release title is `0.1.0 RC · build N "Zohar"`. `N` is this release workflow's run number plus the offset in `BUILD.json`. The same string is in About, on the splash, and in `voxprint-lucent --version`.

Windows: `VoxprintAILucent-0.1.0-rc3-win64.msi`. It is a per-user install (no administrator) under `%LOCALAPPDATA%\Voxprint\Lucent`. The package contains the C++ viewer, the Qt 6.12 runtime, the AVIF and JPEG XL plugins, and the PySide6 tools and Enlarge client.

The measurement bundle is `lucent-0.1.0-rc3-windows.zip`. Unzip it and run `Run-M0.ps1` with Defender real-time protection left on. A cold sample is the first launch after a reboot.

Linux: `voxprint-lucent_0.1.0~rc3_amd64.deb`. The package contains the viewer and the Qt runtime it was built with. AVIF and JPEG XL plugins are not in the Linux package.

`SHA256SUMS` lists every file.

## In this build

- Save, Save as, Save a copy, Export, and Download use the suite tray icons. The floppy-disk save mark is not used. Open stays a folder.
- Save writes `<name>.saved.avif` beside the file. Save a copy writes `<name>-copy.avif`. Export writes `<name>.export.avif`. Download writes `<name>.avif` in the downloads folder. An existing file gets a numeric suffix. Save as is still the format dialog. PNG is not an output.
- Enlarge is started with `voxprint-enlarge --json-progress`. Lucent does not open Enlarge's socket. Discovery and `voxprint-enlarge --capabilities --json` are unchanged. If Enlarge is not installed, the action is disabled and Install Enlarge opens https://github.com/Mitroshenkov87/voxprint-enlarge/releases.
- `voxprint-lucent --dry-run` exercises startup and that hand-off without a window, a GPU, or a real Enlarge. The exact behaviour is in `docs/CLI.md`.

`v0.1.0-rc2` remains the previous published pre-release.
