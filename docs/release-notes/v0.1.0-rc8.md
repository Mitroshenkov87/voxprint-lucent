# VOXPrint AI Lucent v0.1.0-rc8

The GitHub release title is `0.1.0 RC · build 9 "Bahir"`. That number is the `number` field in `BUILD.json`. About, the splash, and `voxprint-lucent --version` use the same string. This note prepares the release. It does not create the tag.

**Windows.** Run `voxprint-lucent-setup-0.1.0-rc8-win-x64.msi`. It installs for the machine, under `C:\Program Files\VOXPrint AI Suite\Lucent`, and asks for an administrator. The Start menu folder is `VOXPrint AI Suite` and the launcher is `VOXPrint AI Lucent`. Publisher is `Aleksandr Mitroshenkov`. The shortcut's AppUserModelID is `VOXPrint.AISuite.Lucent`, and the viewer sets the same id before the first window. A desktop shortcut is an unchecked setup choice. `voxprint-lucent.exe` is the viewer. `voxprint-lucent-cli.exe` is the console entry for the same commands.

Setup moves `%LOCALAPPDATA%\Voxprint` to `%LOCALAPPDATA%\VOXPrint AI Suite` once, before any Python runs, and leaves settings in place. It then removes an older per-user install under `%LOCALAPPDATA%\Voxprint\Lucent`. If that uninstall fails, setup stops. The language list is English, German, Ukrainian, and Latvian. Russian is not offered. Setup can install PowerShell 7.6.9. If that box is left off, or the PowerShell install does not finish, scripts use Windows PowerShell 5.1.

The package contains the C++ viewer, the Qt 6.12 runtime, the Visual C++ runtime, the AVIF and JPEG XL plugins, the PySide6 tools and Enlarge client, and `images\smoke.jpg`.

The measurement bundle is `voxprint-lucent-0.1.0-rc8-win-x64.zip`. Unzip it and run `Run-M0.ps1` with `pwsh`. A cold sample is the first launch after a reboot.

**Linux.** `voxprint-lucent_0.1.0-rc8_amd64.deb` installs the viewer under `/opt/voxprint-ai-suite/lucent/` and links `voxprint-lucent` and `voxprint-lucent-cli` into `/usr/local/bin`. The package version inside the archive stays `0.1.0~rc8`.

**Shared library.** The helper pins voxprint-common v0.5.2 (pull request 28, commit `c3a74eaa5e834391b499af08b110efa37441209d`) by the published wheel and its sha256. Tokens, shell catalogs, and presets are vendored from that tag. Buttons use `button_radius_px`. Model directories, if a caller needs one, go through `voxprint_common.paths.models_dir()`. Lucent still does not ship or run a model.

**Interface.** The window is viewer-first. A slim toolbar has Open, Previous, Next, Zoom, Rotate, Compare, Enlarge, and Settings. The picture fills the window. A thumbnail strip along the bottom can be hidden. Simple mode keeps the preset chips on one row. Expert mode still shows the live values. Every previous command remains on More, the context menu, or the Expert panel. The mark is an original frame-and-lens icon drawn for this suite. voxprint-common v0.5.2 has no Lucent identity colour, so the glyph uses `#5ce1ff`.

**Languages.** The interface no longer includes Russian. English, German, Ukrainian, and Latvian remain, because v0.5.2 ships those catalogs. Russian text inside a picture, including EXIF, is unchanged.

**Enlarge.** Opening the tools window does not probe Enlarge. Check runs that probe in the background, with progress and Cancel, then unloads it. The gate is red until the probe succeeds, and an edit turns it red again. Quick enlarge and Open in Enlarge stay off while the gate is red.
