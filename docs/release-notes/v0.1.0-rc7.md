# VOXPrint AI Lucent v0.1.0-rc7

The GitHub release title is `0.1.0 RC · build 8 "Orah"`. That number is the `number` field in `BUILD.json`. About, the splash, and `voxprint-lucent --version` use the same string.

## Install

**Windows.** Run `VoxprintAILucent-0.1.0-rc7-win64.msi`. It installs for the machine, under `C:\Program Files\VOXPrint AI Suite\Lucent`, and asks for an administrator. The Start menu folder is `VOXPrint AI Suite` and the shortcut is `VOXPrint AI Lucent`. Publisher is `VOXPrint AI Suite`. `voxprint-lucent.exe` is the viewer. `voxprint-lucent-cli.exe` is the console entry for the same commands. The package contains the C++ viewer, the Qt 6.12 runtime, the Visual C++ runtime, the AVIF and JPEG XL plugins, the PySide6 tools and Enlarge client, and `images\smoke.jpg`.

The installer writes `HKLM\Software\VOXPrint\Lucent` (`InstallPath`, `Exe`, `CliExe`, `Version`, `Build`, `IpcName`, `ProtocolVersion`) and the HKLM App Paths keys for both executables. Readers still accept the older `HKCU\Software\Voxprint\Lucent` key.

A per-user install from rc6 (`%LOCALAPPDATA%\Voxprint\Lucent`, display name `Voxprint AI Lucent`) is a different Windows Installer context. The new MSI does not uninstall it: a nested `msiexec` from inside an install is rejected by Windows Installer. Run `remove-legacy-user.ps1` from the install folder first, or remove `Voxprint AI Lucent` in Settings, then install rc7. That script removes the old product only. Files you created under `%LOCALAPPDATA%\Voxprint` stay.

The measurement bundle is `lucent-0.1.0-rc7-windows.zip`. Unzip it and run `Run-M0.ps1` with Defender real-time protection left on. A cold sample is the first launch after a reboot. The cold-start task's trigger expires, and `-ColdResume` unregisters the task even when the run fails before it writes a result. `vm_test.ps1 -Smoke -Json` finds an MSI install and stops a viewer call that does not exit.

**Linux.** `voxprint-lucent_0.1.0~rc7_amd64.deb` installs the viewer under `/opt/voxprint-ai-suite/lucent/` and links `voxprint-lucent` and `voxprint-lucent-cli` into `/usr/local/bin`.
