# VOXPrint AI Lucent v0.1.0-rc7

The GitHub release title is `0.1.0 RC · build 8 "Orah"`. That number is the `number` field in `BUILD.json`. About, the splash, and `voxprint-lucent --version` use the same string.

## Install

**Windows.** Run `voxprint-lucent-setup-0.1.0-rc7-win-x64.msi`. It installs for the machine, under `C:\Program Files\VOXPrint AI Suite\Lucent`, and asks for an administrator. The Start menu folder is `VOXPrint AI Suite` and the shortcut is `VOXPrint AI Lucent`. Publisher is `VOXPrint AI Suite`. `voxprint-lucent.exe` is the viewer. `voxprint-lucent-cli.exe` is the console entry for the same commands. The package contains the C++ viewer, the Qt 6.12 runtime, the Visual C++ runtime, the AVIF and JPEG XL plugins, the PySide6 tools and Enlarge client, and `images\smoke.jpg`.

The installer writes `HKLM\Software\VOXPrint\Lucent` (`InstallPath`, `Exe`, `CliExe`, `Version`, `Build`, `IpcName`, `ProtocolVersion`) and the HKLM App Paths keys for both executables. Readers still accept the older `HKCU\Software\Voxprint\Lucent` key.

A per-user install from rc6 (`%LOCALAPPDATA%\Voxprint\Lucent`, display name `Voxprint AI Lucent`) is a different Windows Installer context, so the MSI cannot remove it during setup. After the installed viewer has shown its window, a background thread starts `msiexec /x {ProductCode} /qn` detached and hidden, writes one line to `%LOCALAPPDATA%\Voxprint\legacy-uninstall.log`, and does not wait. The first pixel is not held for that uninstall. Files you created under `%LOCALAPPDATA%\Voxprint` stay. `remove-legacy-user.ps1` in the install folder is the same uninstall if you want to run it yourself.

The measurement bundle is `voxprint-lucent-0.1.0-rc7-win-x64.zip`. Unzip it and run `Run-M0.ps1` with Defender real-time protection left on. A cold sample is the first launch after a reboot. The cold-start task's trigger expires, and `-ColdResume` unregisters the task even when the run fails before it writes a result. `vm_test.ps1 -Smoke -Json` finds an MSI install and stops a viewer call that does not exit.

**Linux.** `voxprint-lucent_0.1.0-rc7_amd64.deb` installs the viewer under `/opt/voxprint-ai-suite/lucent/` and links `voxprint-lucent` and `voxprint-lucent-cli` into `/usr/local/bin`. The package version inside the archive stays `0.1.0~rc7`.

## Other

For v0.1.x the accepted cold first pixel is 450 ms (JPEG, first launch after reboot). Warm JPEG and WebP stay at 250 ms. A warm full-resolution AVIF or JPEG XL at 12 megapixels or larger stays at 350 ms. Run-M0 and vm_test on the laptop score those gates. The Ubuntu smoke job logs the warm tiny-JPEG time and does not fail when a shared runner is slower.

`--benchmark` from Windows session 0 exits with an error instead of waiting on a desktop that is not there. A benchmark that has not finished in 60 seconds exits as well.
