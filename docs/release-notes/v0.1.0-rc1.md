# Voxprint AI Lucent v0.1.0-rc1

Release candidate for the Windows Server 2025 test. This is a pre-release. The viewer does not need an NVIDIA GPU. Enlarge, when you install that app separately, has its own GPU requirements.

## Install

Windows: `VoxprintAILucent-0.1.0-rc1-win64.msi`. It is a per-user install (no administrator) under `%LOCALAPPDATA%\Voxprint\Lucent`. The package contains the C++ viewer, the Qt 6.12 runtime, the AVIF and JPEG XL plugins, and the PySide6 tools and Enlarge client.

The measurement bundle is `lucent-0.1.0-rc1-windows.zip`. Unzip it and run `Run-M0.ps1` with Defender real-time protection left on. A cold sample is the first launch after a reboot.

Linux: `voxprint-lucent_0.1.0~rc1_amd64.deb`. The viewer and Qt 6.12 are in the package. Tools need Python 3.14. AVIF and JPEG XL plugins are in the Windows installer; this Linux package uses Qt's JPEG and WebP plugins.

Check `SHA256SUMS` against the downloads.

## First run

Open an image with the Start menu shortcut, or `voxprint-lucent photo.jpg`. Left and Right move through the folder. `I` opens the info panel. `voxprint-lucent-tools --enlarge --path photo.jpg` hands the file to Voxprint AI Enlarge when that app is installed, then shows a before/after split.

`voxprint-lucent-tools --check-update` reads this repository's GitHub releases. The viewer does not contact the network to open an image. Diagnostics stay off unless you opt in.

## This candidate does not include

- The product Enlarge server. The client is tested against a mock.
- A monitor colour profile. Embedded profiles are converted to sRGB.
- Linux AVIF and JPEG XL plugins.

Uninstall on Windows from Settings, Apps. On Linux, `sudo apt remove voxprint-lucent`.
