# M2 tools and info

The info panel and the edit tools live in `voxprint-lucent-tools`. The C++ viewer starts that process with `I` and the path of the open file. `--benchmark` does not start it, and `--ping` still answers `pong` without loading Qt.

## What works

- The info panel is read-only: dimensions, format, bit depth, colour profile, frame index, and an EXIF line (make, model, time, orientation) plus a GPS summary. JPEG EXIF is parsed in `voxprint_lucent/info.py`. exiv2 is not used.
- The frame row steps through frames the Qt reader reports, plays them on a short timer when there is more than one, and exports the current frame as AVIF, JPEG XL, or WebP. PNG is rejected. JPEG and HEIC are not frame-export formats.
- Rotate and flip rewrite the JPEG orientation tag in place when that tag is present. Other files, and a JPEG with no tag, are saved as a new AVIF next to the source. The source is left in place.
- Crop writes an AVIF copy. The colour under a click on the preview is copied as hex, with the RGB values shown beside it. Copy path and copy image use the clipboard. Reveal opens the parent folder (Explorer select on Windows). Trash moves the file to the Freedesktop trash or the Windows Recycle Bin.
- English is the default. `LUCENT_LANG=ru` and `LUCENT_LANG=de` switch the labels. The window uses `share/palette.json` through the same stylesheet as the rest of the tools.

## Checks

`tests/test_info.py` checks the crafted JPEG (orientation 6, HTC, the GPS point) and a PNG with no EXIF. `tests/test_edits.py` checks the orientation cycle, the in-place tag rewrite, AVIF crop, WebP export, the PNG rejection, and the trash move. `tests/test_tools_window.py` opens the window on a PNG and checks the fact line and the accent colour `#60a5fa`.
